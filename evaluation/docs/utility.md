# Utility

[🗂️ Dataset guides](../README.md) · [🏠 Project home](../../README.md)

## Evaluation settings

- **Clean:** evaluate task utility without prompt injection.
- **Under injection:** evaluate task utility with prompt injection.

## Datasets

| Dataset | Source |
| :--- | :--- |
| MMLU | [Hugging Face](https://huggingface.co/datasets/cais/mmlu) |
| ARC | [Hugging Face](https://huggingface.co/datasets/allenai/ai2_arc) |
| BBQ | [Upstream repository](https://github.com/nyu-mll/BBQ) |
| GSM8K | [Hugging Face](https://huggingface.co/datasets/openai/gsm8k) |
| AlpacaEval | [Upstream repository](https://github.com/tatsu-lab/alpaca_eval) |

Our utility evaluation builds on [DeepEval](https://github.com/confident-ai/deepeval), with minor changes for prompt-injection settings. We thank the DeepEval contributors for their evaluation framework.
